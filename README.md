# 🛍️ Product Explorer

A modern, professional product catalogue application built with React. Features include product browsing, search, filtering, sorting, shopping cart with quantity management, and user authentication.

![Product Explorer Demo](https://via.placeholder.com/800x400/1a2332/3498db?text=Product+Explorer)

---

## 📋 Features

### 🔐 Authentication
- User login and signup with validation
- Demo credentials provided for testing
- Session management with logout functionality

### 🛍️ Product Catalogue
- 12+ products with images, descriptions, and ratings
- Responsive product grid layout
- Reusable ProductCard components

### 🔍 Search & Filter
- Search products by name in real-time
- Filter by category (Laptops, Phones, Headphones, Wearables, Accessories, Desktops)
- Sort by price (Low to High / High to Low)
- Sort by rating (High to Low)

### 🛒 Shopping Cart
- Add products to cart with quantity management
- Increase/Decrease item quantities
- Remove items from cart
- Real-time cart count and total price calculation
- Cart persists during session

### 💰 Checkout
- Professional checkout flow
- Cart automatically clears after successful checkout
- Order confirmation with total amount

### 📱 Responsive Design
- Fully responsive on all devices
- Mobile-friendly navigation
- Adaptive product grid
